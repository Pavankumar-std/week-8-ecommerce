## Project Overview

ShopSphere is a complete responsive e-commerce frontend application developed using React.

The application combines the frontend concepts learned throughout the internship, including React components, React Router, Context API, external API integration, Local Storage, authentication simulation, shopping cart functionality, checkout validation, loading states and responsive design.

---

## Main Features

- Product catalog
- Product search
- Category filtering
- Product sorting
- Product detail page
- Shopping cart
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Persistent cart using Local Storage
- User registration
- User login
- User logout
- Checkout form
- Form validation
- Order confirmation
- Loading states
- API error handling
- Responsive design
- Lazy loading
- Code splitting
